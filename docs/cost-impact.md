# Cost impact of the analysis-first refactor

The repository does not contain provider billing or usage records, so this file
does not claim a dollar amount or a confirmed saving.

Potential recurring costs removed from the active request path:

- Hugging Face and other video-provider inference calls.
- Internal rendering worker execution and its scheduled invocations.
- New video artifact uploads generated by the application.
- Automatic YouTube upload or publish requests.

The code now returns `410 PRODUCTION_RETIRED` for production creation, worker,
retry, upload, and publish routes. The production worker schedule was removed,
and the provider dependency was removed from `package.json`. Existing cloud
subscriptions, stored artifacts, and credentials cannot be cancelled by this
repository change; review them separately in provider dashboards.

The active cost surface is limited to configured Supabase, YouTube API, and
optional AI adapter usage. No paid AI provider is required for analytics or draft
review when the adapter is unconfigured.
